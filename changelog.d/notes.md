- Note layout settings: switch the abstract, bibliography entry, metadata fields, links, Zotero notes and the Synthesis scaffold on or off, rename the callout types, set the Synthesis lines and the annotations heading. A switched-off part keeps its place as an empty generated block; the defaults write exactly the notes 0.6.0 wrote.
- Theme hooks: styles.css declares CSS variables for the highlight colours (also used by `<mark>` backgrounds, lighter in dark themes), status and row-state colours and sidebar card spacing, for themes and snippets to override.
- Fields by item type (Note layout, off by default): the metadata callout lists the fields of the item's type (university and thesis type for a thesis, institution and report number for a report, proceedings and conference for a conference paper, website for a web page, repository and archive ID for a preprint, and so on), plus the raw date, short title, language, access date, `key: value` lines of Extra and the dates the item was added and modified. Unedited metadata blocks refresh on the next update; edited ones stay.
- Zotero rich text in item titles and in annotation text and comments now reads as Markdown: `<i>`/`<em>` become italics, `<b>`/`<strong>` bold, `<sup>`/`<sub>` stay superscript/subscript, `nocase` and small-caps spans keep their text and `<br>` breaks the line. Other or unpaired tags are still shown literally; DOIs, URLs, citekeys, tags and the frontmatter keep Zotero's text. The annotation sidebar shows the text without the tags. Unedited blocks pick up the new rendering on the next update.
- An image annotation whose image is not in Zotero's cache is now written as an `[!Image]` callout that says so and links to it in Zotero (with its comment and tags), instead of an empty highlight. The annotation sidebar shows the same text. Unedited blocks refresh on the next update.
- Join continued highlights (Note layout, off by default): a highlight whose Zotero comment starts with `+` is added to the highlight before it in the same attachment, so a passage split across a column or page reads as one block (`p. 3–4`, texts joined with ` … `, comments without the `+`, tags merged). The block keeps the first highlight's ID; a continuation's existing block is kept as it is. Image annotations are never joined, and the annotation sidebar marks continuations.
