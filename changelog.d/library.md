- Fielded search in the literature pickers (Search literature, Import literature note, Insert bibliography, Find notes citing a source and the other picker commands): `author:`, `title:`, `year:2019-2021` (also `2019-` and `-2021`), `tag:`, `col:<collection path>` (subcollections included), `lib:<library name or ID>`, `type:<item type>` and `has:pdf|note|annotations`, each negatable with a leading `-`; quote values with spaces (`col:"Thesis/Related work"`). Unknown fields stay plain text, and plain text ranks exactly as before. The `[@` citekey suggester honours the same field prefixes (one term, no spaces).
- Clicking the status-bar item now opens a menu instead of only testing the connection: Test Better BibTeX connection, Refresh citekey index (disabled while a refresh runs or the legacy plugin is enabled), Diagnose index and links, Open references sidebar, Open annotations sidebar, Open settings and Copy status JSON. Opening the menu never contacts Better BibTeX; the tooltip names what needs attention (no index, stale index, legacy plugin, failed call).
- New command Diagnose setup (also in the status-bar menu): a report-only setup doctor that checks Zotero and Better BibTeX versions, the legacy plugin, the index, Git exposure of the index and cache, whether Obsidian's PDF library loads, whether other registered vaults' note maps can be read, and notes in the literature folder that belong to no entry or carry Better Notes sync frontmatter. Rows that name notes open them; Copy report copies a plain-text report with vault-relative paths and a summary of this session's last 50 Better BibTeX calls (kept in memory only). Nothing is fixed automatically.
- Agents: `diagnostics --env` adds the same checks as `environment.checks` (contract addition; an older plugin is refused with `plugin-too-old`).
- New commands Open Zotero selection, Import Zotero selection and Cite Zotero selection read the items selected in Zotero's library pane when you run them (no listener, no polling). One item opens its literature note (or the import preview when the vault has none yet) or its import preview; several are listed to pick one; an empty selection says so. Items are matched to the saved index by library and item key, never by a first match, and items the index does not have yet are named with a hint to refresh. Cite inserts a Pandoc citation (`[@a; @b]`) at the cursor, copies it instead when the note changed while Zotero was read, and names cited items that have no literature note yet. Selecting only notes or attachments counts as no selection.
- New command Copy Zotero action script: copies a script for the Zotero add-on Actions & Tags, with this vault's name in it, that opens the selected item's literature note or its import preview from Zotero's item or reader menu, a shortcut or an event. It only launches the existing `obsidian://cmds-zotero` link; nothing is installed into or changed in Zotero. Attachments, child notes and annotations stand for their parent item; with several items selected it points to Open or Import Zotero selection. Needs Zotero 10.0.3 or later; setup steps in `docs/zotero-side.md`.
