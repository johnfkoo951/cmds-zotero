- Fielded search in the literature pickers (Search literature, Import literature note, Insert bibliography, Find notes citing a source and the other picker commands): `author:`, `title:`, `year:2019-2021` (also `2019-` and `-2021`), `tag:`, `col:<collection path>` (subcollections included), `lib:<library name or ID>`, `type:<item type>` and `has:pdf|note|annotations`, each negatable with a leading `-`; quote values with spaces (`col:"Thesis/Related work"`). Unknown fields stay plain text, and plain text ranks exactly as before. The `[@` citekey suggester honours the same field prefixes (one term, no spaces).
- Clicking the status-bar item now opens a menu instead of only testing the connection: Test Better BibTeX connection, Refresh citekey index (disabled while a refresh runs or the legacy plugin is enabled), Diagnose index and links, Open references sidebar, Open annotations sidebar, Open settings and Copy status JSON. Opening the menu never contacts Better BibTeX; the tooltip names what needs attention (no index, stale index, legacy plugin, failed call).
